Study design

Methodology

A unified experimental pipeline for classification, reliability assessment, and biological interpretation of fixed-length promoter sequences.

Data and tasks

Binary promoter classification

5,258 training and 1,315 test sequences: Non-Promoter versus Promoter, with near-balanced class counts.

Six-class sigma-factor classification

2,315 training and 583 test promoters labeled Sigma24, Sigma28, Sigma32, Sigma38, Sigma54, or Sigma70. Sigma70 is the majority class.

All sequences are 81 bp. The repository dataset audit reports no invalid DNA characters.

Preprocessing and representation

Loaders parse the processed CD-HIT train/test FASTA files and assign integer labels. CNN inputs use one-hot A/C/G/T channels. Explicit k-mer experiments enumerate normalized count vectors: 5-mers for binary models and 3-mers for sigma models.

CNN architecture

The implemented 1D CNN uses three convolution blocks (64/128/256 channels; kernels 7/5/3), batch normalization, ReLU activations, max pooling, adaptive max pooling, and a dropout-regularized 128-unit classifier head. The sigma experiments use class-weighted cross-entropy; the selected “safe” run uses ordinary shuffled batches, a lower learning rate, and validation macro-F1 model selection.

Hybrid CNN + k-mer model

A sequence branch learns convolutional features while a dense branch learns from k-mer frequencies. Their 128- and 64-dimensional representations are concatenated and classified by a dropout-regularized fusion head.

Reliability and evaluation

Calibration

Post-hoc temperature scaling is evaluated using expected calibration error (ECE), maximum calibration error, Brier score, negative log-likelihood, and reliability diagrams.

Uncertainty

Repeated stochastic forward passes with dropout enabled estimate predictive entropy, variance, and mutual information.

Split conformal prediction

Calibration scores define thresholds for 90% and 95% target coverage. The study reports empirical coverage, set size, singleton/empty rates, and class-wise behavior.

Evaluation design

Held-out metrics include accuracy, macro/weighted F1, MCC, AUROC, and AUPRC. Combined-data stratified five-fold CV separately measures model stability.

Biological and error analysis

Position-frequency profiles, k-mer cosine similarity, class imbalance, confusion pairs, class-wise uncertainty, and conformal behavior connect statistical failure modes with sequence-pattern overlap and limited minority-class support.
