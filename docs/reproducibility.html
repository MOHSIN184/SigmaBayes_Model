Reproducibility

Run these repository scripts from the project root; outputs are written to results/.

Environment

python -m venv .venv
# Windows: activate .venv/Scripts/Activate.ps1
# macOS/Linux: source .venv/bin/activate
python -m pip install --upgrade pip
pip install -r requirements.txt

Dependencies are NumPy, pandas, scikit-learn, Matplotlib, PyTorch, tqdm, and Jupyter. Requirements are unpinned; record package versions for archival reruns.

Data audit and experiments

python scripts/run_dataset_check.py
python scripts/run_binary_experiment.py
python scripts/run_sigma_experiment.py
python scripts/run_sigma_improved_experiment.py
python scripts/run_sigma_safe_experiment.py
python scripts/run_kmer_baselines.py
python scripts/run_kmer_reliability.py
python scripts/run_hybrid_experiment.py

These scripts train and evaluate models and generate metric CSVs, reliability diagrams, uncertainty tables, and conformal outputs. Reruns may overwrite matching files.

Stability, figures, and checks

python scripts/run_cross_validation.py
python scripts/run_biological_error_analysis.py
python scripts/generate_publication_package.py
python scripts/final_project_check.py

Calibration and conformal logic live in src/calibration.py and src/conformal.py. Five-fold training is computationally intensive.

View and deploy

python -m http.server 8000 --directory docs
# visit http://localhost:8000

Or open docs/index.html. For Pages, push to GitHub, select “GitHub Actions” in Settings → Pages, and let the included workflow deploy docs/.
